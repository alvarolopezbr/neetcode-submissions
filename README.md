# NeetCode 150 in Python

My solutions to the NeetCode 150, one problem a day, written in Python. I'm working through it to build up my data structures and algorithms, which is the foundation for data work and technical interviews.

## How it's organised

Each problem has its own folder. Files named `submission-0`, `submission-1` and so on are separate attempts, so some problems have more than one approach.

## Solved so far

| Problem | Approach | Time | Space |
|---|---|---|---|
| Contains Duplicate | Set lookup | O(n) | O(n) |
| Valid Anagram | Counter comparison, or sorting both strings | O(n), or O(n log n) | O(n) |
| Two Sum | One-pass hash map | O(n) | O(n) |

Solutions sync automatically from [NeetCode.io](https://neetcode.io), so this table is updated by hand.
